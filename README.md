# Polystore

## Команда
- Валентин Сидоренко
- Юрій Поліщук 

## Опис
Маркетплейс ассетів для розробників ігор: 3D-моделей, текстур, звуків, шейдерів та готових систем для Unity, Unreal Engine.
Інді-розробники можуть швидко знайти й купити потрібний контент, а автори отримують зручне місце, щоб продавати свої роботи.

## Ролі
- **Гість:** переглядає каталог, шукає та фільтрує ассети, дивиться 3D-превʼю, читає відгуки.
- **Покупець:** купує та завантажує ассети, має бібліотеку покупок, залишає відгуки, отримує сповіщення про оновлення.
- **Автор:** завантажує та редагує свої ассети, публікує нові версії зі списком змін, бачить статистику продажів.
- **Адміністратор:** керує користувачами, ролями, категоріями та рушіями.

## Основний функціонал
- Каталог з пошуком, фільтрами (категорія, рушій, ціна, ліцензія) та сортуванням
- Сторінка ассета з галереєю, інтерактивним 3D-превʼю, характеристиками та відгуками
- Сторінки авторів з їхніми роботами
- Кошик і покупка, особиста бібліотека куплених ассетів
- (???????) версіонування ассетів зі списком змін (changelog)
- Рейтинги та відгуки
- Реєстрація та вхід через JWT

## Особливість проєкту
- **3D-превʼю в браузері.** Моделі можна обертати й роздивлятися прямо на сторінці, без скачування.
- **Автоматична перевірка файлів.** Після завантаження ассет у фоні проходить перевірку формату, аналіз метаданих (кількість полігонів, текстури).
- **Нотифікації на email.** Автори дізнаються про продажі, покупці про нові версії.
